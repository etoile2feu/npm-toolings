# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you want to report a vulnerability about my software, do NOT open an issue, contact me :
- by Discord @etoile2feu
- or by email etoilesoftwares@gmail.com.

If the vulnerability is linked to a dependency you have to report it to the owner of it, but if it's because this package didn't have an updated dependency you have to contact me.
