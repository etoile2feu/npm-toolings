# npm-toolings V1.0.0

A new package to help you manage your npm packages with a gui.

Use it with :

``npm install npm-toolings -g``

``npm-toolings``

Key features :

- A very beautiful and fast GUI
- security measures focused on supply chain attack
- some options

This readme isn't finished yet as the software is in it's early days.
